# tagid · social media files

Public images and videos for scheduled Tagid posts. Files here are fetched by the scheduler by URL:
`https://raw.githubusercontent.com/ranzadok/media/main/tagid/posts/<file>`

One file per post, named `YYYY-MM-DD-<slug>.jpg` or `.mp4`. Nothing private goes here.

`videos/index.json`: a video whose `published` field is not empty was already posted. Do not post it again. After posting a video, fill in its `published` field with the date.

`posts/opening.jpg` was already posted by the owner. Do not post it again.
